# Ali Alsaida — Front-End Portfolio

A responsive personal portfolio built with HTML, CSS, and JavaScript, using a white-and-blue visual identity and a supplied profile photo.

## Files
- `index.html` — page structure and content
- `style.css` — responsive styling
- `script.js` — mobile navigation interaction
- `assets/ali-profile.png` — profile portrait

## Publish or update with GitHub Pages
1. Open your portfolio repository on GitHub.
2. Choose **Add file → Upload files**.
3. Upload `index.html`, `style.css`, and `script.js`, plus the `assets` folder containing `ali-profile.png`.
4. Commit the changes to the `main` branch.
5. In **Settings → Pages**, make sure the source is **Deploy from a branch**, branch is `main`, and folder is `/(root)`.
6. Wait for GitHub Pages to finish deploying, then refresh your public site.

Important: keep the `assets` folder and `ali-profile.png` at the exact path shown above, otherwise the portrait will not load.
